# Issue #8 — Write an SEO-friendly title and meta description

**Tier:** Beginner (1pt)

## What to build

Take an existing page and write a `<title>` and `<meta name="description">` that accurately and specifically describe its content, following SEO best practices for length.

## Requirements

- `<title>` is unique, descriptive, and under 60 characters
- `<meta name="description">` is specific to the page's actual content and between 50-160 characters
- Neither tag contains generic placeholder text (e.g. "My Page", "Description here")

## Where to put your work

```
challenges/block-2/08-seo-title-meta-description/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Title and description values are specific to the page's actual content, not placeholder text
- PR opened against `main`, linked to this issue (`Addresses #8`)
