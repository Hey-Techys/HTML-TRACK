# Issue #11 — Build an event registration form with mixed input types

**Tier:** Intermediate (3pt)

## What to build

Build a registration form for an event that combines several input types: text, email, date, a `<select>` for ticket type, and a radio group for meal preference.

## Requirements

- Text input for full name, `required`
- Email input, `required`
- `<input type="date">` for arrival date
- `<select>` with at least 3 `<option>`s for ticket type
- A radio group (in a `<fieldset>`/`<legend>`) for meal preference with at least 2 options

## Where to put your work

```
challenges/block-2/11-event-registration-form/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- All five input types are present and each has an associated label
- PR opened against `main`, linked to this issue (`Addresses #11`)
