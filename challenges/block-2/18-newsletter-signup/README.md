# Issue #18 — Build a newsletter signup form with a required email field

**Tier:** Beginner (1pt)

## What to build

Create a short newsletter signup form: a heading, one required email input with a visible label, and a subscribe button.

## Requirements

- Form has exactly one `<input type="email">`, marked `required`
- Input has a visible, associated `<label>`
- Submit button text clearly describes the action (e.g. "Subscribe")
- Form cannot be submitted with an empty or invalid email

## Where to put your work

```
challenges/block-2/18-newsletter-signup/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Form cannot be submitted with an empty or invalid email
- PR opened against `main`, linked to this issue (`Addresses #18`)
