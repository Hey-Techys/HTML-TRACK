# Issue #7 — Add aria-label to icon-only social links

**Tier:** Beginner (1pt)

## What to build

Build a small row of social media links that use icon images with no visible text, and make each one accessible with `aria-label`.

## Requirements

- At least 3 icon-only links (e.g. Twitter, GitHub, LinkedIn)
- Each link's `<img>` uses `alt=""` (decorative, since the label does the describing)
- Each `<a>` has an `aria-label` describing its destination (e.g. `aria-label="Visit my GitHub profile"`)

## Where to put your work

```
challenges/block-2/07-icon-button-aria-label/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Each link has a valid href and a descriptive aria-label
- PR opened against `main`, linked to this issue (`Addresses #7`)
