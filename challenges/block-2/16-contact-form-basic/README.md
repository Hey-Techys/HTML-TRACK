# Issue #16 — Build a basic contact form with labeled inputs

**Tier:** Beginner (1pt)

## What to build

Create a contact form with fields for name, email, and message. Every input must have a properly associated `<label>`.

## Requirements

- Form includes `name`, `email`, and `message` fields
- Every `<input>`/`<textarea>` has a `<label>` connected via `for`/`id`
- Includes a `<button type="submit">` to send the form
- Every input has a matching, correctly associated `<label>`

## Where to put your work

```
challenges/block-2/16-contact-form-basic/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Every input has a matching, correctly associated `<label>`
- PR opened against `main`, linked to this issue (`Addresses #16`)
