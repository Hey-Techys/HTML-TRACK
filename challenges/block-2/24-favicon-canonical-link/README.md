# Issue #24 — Add a favicon and a canonical link tag

**Tier:** Beginner (1pt)

## What to build

Add a favicon so the page shows an icon in the browser tab, and add a `<link rel="canonical">` tag pointing to the page's preferred URL.

## Requirements

- `<link rel="icon">` pointing to a valid image file
- `<link rel="canonical">` with an `href` pointing to the full, preferred URL of the page
- Both tags are placed inside `<head>`
- Favicon displays in the browser tab when the page is opened

## Where to put your work

```
challenges/block-2/24-favicon-canonical-link/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Favicon displays in the browser tab when the page is opened
- PR opened against `main`, linked to this issue (`Addresses #24`)
