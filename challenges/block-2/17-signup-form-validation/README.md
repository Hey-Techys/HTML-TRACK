# Issue #17 — Add native validation attributes to a signup form

**Tier:** Beginner (1pt)

## What to build

Build a signup form with `name`, `email`, and `password` fields, and add native HTML validation attributes so the browser blocks submission of incomplete or malformed data.

## Requirements

- `name` input uses `required` and `minlength="2"`
- `email` input uses `type="email"` and `required`
- `password` input uses `type="password"`, `required`, and `minlength="8"`
- Submitting the form with invalid or missing data shows the browser's native validation message
