# Issue #19 — Group related radio inputs with `<fieldset>` and `<legend>`

**Tier:** Beginner (1pt)

## What to build

Build a short form asking for a preferred contact method (email, phone, or text) using radio buttons, grouped correctly with `<fieldset>` and `<legend>`.

## Requirements

- Radio inputs are wrapped in a `<fieldset>`
- `<fieldset>` includes a `<legend>` describing the group (e.g. "Preferred Contact Method")
- All radio inputs share the same `name` attribute
- Each radio input has its own associated `<label>`
