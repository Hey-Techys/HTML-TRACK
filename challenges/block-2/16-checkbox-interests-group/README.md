# Issue #16 — Add a checkbox group for 'select your interests'

**Tier:** Beginner (1pt)

## What to build

Build a short form that lets users pick one or more interests using checkboxes, grouped correctly with `<fieldset>` and `<legend>`.

## Requirements

- At least 4 `<input type="checkbox">` options (e.g. Web Design, Data, Cloud, Mobile)
- Checkboxes are wrapped in a `<fieldset>` with a `<legend>` (e.g. "Select your interests")
- Every checkbox has its own `<label>` connected via `for`/`id`
- All checkboxes share one `name` and each has a distinct `value`

## Where to put your work

```
challenges/block-2/16-checkbox-interests-group/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Every checkbox is individually labeled and the group has a legend
- PR opened against `main`, linked to this issue (`Addresses #16`)
