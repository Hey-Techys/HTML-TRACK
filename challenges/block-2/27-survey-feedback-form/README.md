# Issue #27 — Build a feedback survey form with checkboxes and a rating group

**Tier:** Intermediate (3pt)

## What to build

Build a feedback form that asks which features the user liked (checkboxes), a satisfaction rating (radio group), and an open-ended comment box.

## Requirements

- A `<fieldset>`/`<legend>` group of at least 3 checkboxes for "features you liked", each individually labeled
- A `<fieldset>`/`<legend>` radio group for a satisfaction rating (e.g. 1–5), sharing one `name`
- A `<textarea>` with a label for open-ended comments
- Checkboxes allow multiple selections; radio group allows only one

## Where to put your work

```
challenges/block-2/27-survey-feedback-form/(your-name)/index.html
```

## Definition of done

- Builds and displays correctly in a browser
- Checkboxes allow multiple selections; radio group allows only one
